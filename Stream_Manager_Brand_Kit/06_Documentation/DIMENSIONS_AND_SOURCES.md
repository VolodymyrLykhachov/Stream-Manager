# Asset dimensions and official reference sources

Verified October 11, 2026.

Home Assistant add-on (currently referred to in developer documentation as an app):
- `icon.png`: square, recommended 128x128 px.
- `logo.png`: recommended approximately 250x100 px.
- https://developers.home-assistant.io/docs/apps/presentation/
- https://developers.home-assistant.io/docs/apps/configuration/

Custom integration branding, optional and separate from add-on packaging:
- Icon PNG normal 256x256, @2x 512x512.
- Since Home Assistant 2026.3, custom integrations can ship local `brand/` images.
- https://developers.home-assistant.io/docs/core/integration/brand_images/
- https://developers.home-assistant.io/blog/2026/02/24/brands-proxy-api/
- https://github.com/home-assistant/brands/blob/master/README.md

GitHub social preview:
- Recommended 1280x640 px, PNG/JPG/GIF under 1 MB.
- https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview

Home Assistant official mark is trademarked:
- https://github.com/home-assistant/assets/blob/master/logo/README.md
